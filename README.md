# HELLHONK

An original goose-themed retro FPS. Episode 1: **Fowl Waters** has six levels, eight enemy types, a boss, six weapons and 2-player online co-op. All the art, sound and music are generated by the game's own code.

**Play:** download `HellHonk.exe` from the [latest release](https://github.com/chaz434343434/hellhonk/releases/latest) and run it. You don't need Python. The game updates itself: when a new release is out, it downloads it and restarts on the title screen.

Website: https://chaz434343434.github.io/hellhonk/

## Controls
WASD move · mouse/arrows turn · click/Ctrl fire · E/Space/right-click use · 1–6 or wheel switch weapons · Shift walk · Tab automap · M music · Esc menu

## Co-op
One player picks **CO-OP: HOST GAME**, and the other picks **CO-OP: JOIN GAME** and types the host's IP.
- Over the internet, use a VPN like Tailscale, Radmin VPN or ZeroTier, or forward TCP port **29331** on the host's router.
- Both players need the same version. The auto-updater handles that.

## Running from source
Needs Python 3.9 with pygame and numpy.
```
py -3.9 hellhonk.py                 # play
py -3.9 hellhonk.py --selftest out  # headless tests + screenshots
```

## Releasing an update
```
py -3.9 release.py 1.0.1 "What changed"
```
This sets the version, runs the self-test, builds the exe, commits, tags, pushes and publishes a GitHub release. Everyone's game picks it up the next time it starts.
