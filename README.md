# HONK

An original goose-themed retro FPS. Three episodes, **Fowl Waters**, **Downstream** and **The Roost of Ash**, make 16 levels with 13 enemy types (three of them bosses), six weapons and online co-op for up to 3 players. All the art, sound and music are generated by the game's own code.

**Play:** get it from the [latest release](https://github.com/chaz434343434/hellhonk/releases/latest). You don't need Python.
- **Windows:** `HellHonk.exe`
- **Mac:** `HellHonk-mac-arm64.zip` (Apple Silicon) or `HellHonk-mac-intel.zip`. Unzip it, drag the app into Applications, then on first open use System Settings → Privacy & Security → **Open Anyway**.

The game updates itself: when a new release is out, it downloads it and restarts on the title screen. Windows and Mac players can play co-op together.

Website: https://chaz434343434.github.io/hellhonk/

## Controls
WASD move · mouse/arrows turn · click/Ctrl fire · E/Space/right-click use · 1–6 or wheel switch weapons · Shift walk · Tab automap · M music · Esc menu

## Co-op
One player picks **CO-OP: HOST GAME**, and up to two others pick **CO-OP: JOIN GAME** and type the host's IP. Players can join mid-level.
- Over the internet, use a VPN like Tailscale, Radmin VPN or ZeroTier, or forward TCP port **29331** on the host's router.
- Both players need the same version. The auto-updater handles that.

## Running from source
Needs Python 3.9+ with pygame and numpy (`pip install -r requirements.txt`). Works on Windows and macOS; on a Mac use `python3 hellhonk.py`.
```
py -3.9 hellhonk.py                 # play
py -3.9 hellhonk.py --selftest out  # headless tests + screenshots
```

## Releasing an update
```
py -3.9 release.py 1.0.1 "What changed"
```
This sets the version, runs the self-test, builds the exe, commits, tags, pushes and publishes a GitHub release. A GitHub Actions workflow (`.github/workflows/mac.yml`) then builds and tests both Mac versions and attaches them to the same release. Everyone's game picks it up the next time it starts.
