Hell has flooded the park pond. You are one very angry goose with a brass horn, an egg cannon and no plan to forgive anyone. HELLHONK is a fast 90s-style shooter: keycards, secret walls, exploding barrels, a face in the status bar that gets roughed up as you take damage, and a honk-metal soundtrack.

HOW TO PLAY

  1. Download HellHonk.exe and put it in its own folder.
  2. Run it. Windows may show "Windows protected your PC" because the exe isn't code-signed. Click More info → Run anyway.
  3. Pick START on the title screen. Finished levels unlock in the level picker.

CO-OP WITH A FRIEND

  1. Both of you download the same version. The auto-updater keeps you matched.
  2. The host picks a level, then CO-OP: HOST GAME. The screen shows the host's IP address. Allow it through Windows Firewall if asked.
  3. The friend picks CO-OP: JOIN GAME, types that IP and presses Enter.

On the same Wi-Fi it just works. Across the internet, both install a free VPN like Tailscale, Radmin VPN or ZeroTier and use the IP it gives the host. The other option is forwarding TCP port 29331 on the host's router.
